av-pc = <b>computer (windows 10/11, mac, linux):</b> saves and shows sites. https uses the <b>curl</b> program that already comes with the system; the server ships no encryption library of its own.
av-win7 = <b>windows 7:</b> shows and imports, but does not download sites (no curl).
av-cel = <b>phones (android, iphone, others):</b> open everything that was saved, over the wi-fi of the computer running the server. saving directly on a phone is not possible: phone browsers do not let a page download other sites.
av-login = <b>subscriptions and pages behind a login:</b> the server never uses your password anywhere. save the page with ctrl+s or as pdf and put it in <b>arquivo/importar</b>.
av-js = <b>sites that depend on javascript:</b> the server uses the browser already on the computer (edge, chrome, chromium or brave), invisible, with an empty profile that is deleted at the end (none of your logins). all of its traffic goes through a filter that blocks the local network, the browser's own services and trackers. it is not an extension and installs nothing. still not working: logins, infinite scroll and interactive buttons.
av-imagens = <b>photos:</b> hidden data (camera, date, gps location) is removed without changing any pixel. with <b>arquivo_economizar_imagens = sim</b> in config.txt, big photos become webp, much smaller, with an almost invisible difference.
av-sem-scripts = <b>copies open without scripts</b> and without fetching anything from the internet (no trackers): they are a "browsable snapshot" of the page.
av-robots = <b>the server respects robots.txt</b> (when a site asks not to be copied) and downloads slowly so as not to overload anyone.
av-resp = <b>responsibility:</b> the copy stays only on this computer and nobody can delete it from outside, but the law still applies to whoever keeps it (copyright, personal data). keeping it for personal use is usually accepted; sharing someone else's site may count as redistribution.
sobre-1 = This is <b>Local Server</b>. Similar to Cloudflare: it keeps sites and serves them to the browser. The difference is that it lives <b>on this computer</b> and works <b>without internet</b>.
sobre-cf = lives on the internet. anyone in the world can open it, but only with internet.
sobre-ls = lives here. opens on this computer and, if you turn it on, on devices on the same wi-fi. works without internet and you are in control.
sobre-2 = The server is the <b>building</b>; each folder inside <b>sites</b> is a <b>resident</b>. The <b>site archive</b> keeps copies of websites, with a new version whenever they change, like a personal museum. The whole folder can be copied to a USB stick or another computer and works the same.
