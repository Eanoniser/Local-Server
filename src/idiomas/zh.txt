av-pc = <b>电脑（windows 10/11、mac、linux）：</b>保存并显示网站。https 使用系统自带的 <b>curl</b> 程序；服务器不自带加密库。
av-win7 = <b>windows 7：</b>可以显示和导入，但不能下载网站（没有 curl）。
av-cel = <b>手机（android、iphone 等）：</b>通过运行服务器的电脑所在的 wi-fi 打开所有已保存的内容。无法直接在手机上保存：手机浏览器不允许网页下载其他网站。
av-login = <b>付费订阅和需要登录的页面：</b>服务器从不使用你的密码。用 ctrl+s 或 pdf 保存页面，然后放进 <b>arquivo/importar</b>。
av-js = <b>依赖 javascript 的网站：</b>服务器以不可见方式使用电脑上已有的浏览器（edge、chrome、chromium 或 brave），配合一个结束后即删除的空白配置文件（不含你的任何登录信息）。它的所有流量都经过一个过滤器，阻止访问局域网、浏览器自身的服务和跟踪器。这不是扩展程序，也不安装任何东西。仍然无法使用：登录、无限滚动和交互按钮。
av-imagens = <b>照片：</b>隐藏数据（相机、日期、gps 位置）会被删除，不改变任何像素。在 config.txt 中设置 <b>arquivo_economizar_imagens = sim</b> 后，大照片会转为 webp，小得多，差别几乎看不出来。
av-sem-scripts = <b>副本在打开时不运行脚本</b>，也不从互联网获取任何内容（没有跟踪器）：它们是页面的"可浏览快照"。
av-robots = <b>服务器遵守 robots.txt</b>（当网站要求不被复制时），并且下载得很慢，不给任何人造成负担。
av-resp = <b>责任：</b>副本只保存在这台电脑上，别人无法从外部删除，但保存者仍须遵守法律（版权、个人数据）。为个人用途保存通常是被接受的；分享他人的网站可能构成再分发。
sobre-1 = 这是 <b>Local Server</b>。类似 Cloudflare：保存网站并提供给浏览器。不同之处在于它就在<b>这台电脑上</b>，而且<b>无需联网</b>。
sobre-cf = 在互联网上。世界上任何人都能打开，但必须联网。
sobre-ls = 就在这里。在这台电脑上打开；如果你开启共享，同一 wi-fi 下的设备也能打开。无需联网，由你掌控。
sobre-2 = 服务器是一栋<b>楼</b>；<b>sites</b> 里的每个文件夹是一位<b>住户</b>。<b>网站存档</b>保存网站的副本，每次变化都会存一个新版本，就像一座私人博物馆。整个文件夹可以复制到 U 盘或另一台电脑上，照样能用。
