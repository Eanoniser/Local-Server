av-pc = <b>computador (windows 10/11, mac, linux):</b> guarda e mostra sites. o https usa o programa <b>curl</b> que já vem no sistema; o servidor não traz biblioteca de criptografia própria.
av-win7 = <b>windows 7:</b> mostra e importa, mas não baixa sites (não tem curl).
av-cel = <b>celulares (android, iphone, outros):</b> abrem tudo o que foi guardado pelo wi-fi do computador que roda o servidor. guardar direto no celular não é possível: os navegadores de celular não deixam uma página baixar outros sites.
av-login = <b>assinaturas e páginas com login:</b> o servidor não entra com sua senha em lugar nenhum. salve a página com ctrl+s ou em pdf e coloque em <b>arquivo/importar</b>.
av-js = <b>sites que dependem de javascript:</b> o servidor usa o navegador que já está no computador (edge, chrome, chromium ou brave), invisível, com um perfil vazio que é apagado no fim (sem seus logins). todo o tráfego dele passa por um filtro que bloqueia a rede interna, serviços do próprio navegador e rastreadores. não é extensão e não instala nada. continuam sem funcionar: login, rolagem infinita e botões interativos.
av-imagens = <b>fotos:</b> os dados escondidos (câmera, data, localização gps) são apagados sem mudar nenhum pixel. com <b>arquivo_economizar_imagens = sim</b> no config.txt, fotos grandes viram webp, bem menores, com diferença quase invisível.
av-sem-scripts = <b>as cópias abrem sem scripts</b> e sem buscar nada na internet (sem rastreadores): são uma "foto navegável" da página.
av-robots = <b>o servidor respeita o robots.txt</b> (quando o site pede para não ser copiado) e baixa devagar para não sobrecarregar ninguém.
av-resp = <b>responsabilidade:</b> a cópia fica só neste computador e ninguém consegue apagá-la daqui, mas as leis continuam valendo para quem guarda (direitos autorais, dados pessoais/lgpd). guardar para uso pessoal costuma ser aceito; compartilhar o site de outra pessoa pode ser redistribuição.
sobre-1 = Este é o <b>Local Server</b>. Parecido com a Cloudflare: guarda sites e entrega para o navegador. A diferença é que ele fica <b>neste computador</b> e funciona <b>sem internet</b>.
sobre-cf = fica na internet. qualquer pessoa no mundo abre, mas só com internet.
sobre-ls = fica aqui. abre neste computador e, se você ligar, nos aparelhos do mesmo wi-fi. funciona sem internet e quem controla é você.
sobre-2 = O servidor é o <b>prédio</b>; cada pasta dentro de <b>sites</b> é um <b>morador</b>. O <b>arquivo de sites</b> guarda cópias de sites da internet, com uma versão nova a cada mudança, como um museu pessoal. A pasta inteira pode ser copiada para um pendrive ou outro computador e funciona igual.
