av-pc = <b>computer (windows 10/11, mac, linux):</b> speichert und zeigt websites. https nutzt das programm <b>curl</b>, das schon zum system gehört; der server bringt keine eigene verschlüsselungsbibliothek mit.
av-win7 = <b>windows 7:</b> zeigt und importiert, lädt aber keine websites herunter (kein curl).
av-cel = <b>handys (android, iphone, andere):</b> öffnen alles gespeicherte über das wlan des computers, auf dem der server läuft. direkt auf dem handy speichern geht nicht: handy-browser erlauben einer seite nicht, andere websites herunterzuladen.
av-login = <b>abos und seiten mit anmeldung:</b> der server benutzt nie dein passwort. speichere die seite mit strg+s oder als pdf und lege sie in <b>arquivo/importar</b>.
av-js = <b>websites, die javascript brauchen:</b> der server nutzt den browser, der schon auf dem computer ist (edge, chrome, chromium oder brave), unsichtbar, mit einem leeren profil, das am ende gelöscht wird (keine deiner anmeldungen). sein ganzer verkehr läuft durch einen filter, der das lokale netz, die dienste des browsers selbst und tracker blockiert. es ist keine erweiterung und installiert nichts. weiterhin ohne funktion: anmeldungen, endloses scrollen und interaktive knöpfe.
av-imagens = <b>fotos:</b> versteckte daten (kamera, datum, gps-standort) werden entfernt, ohne ein pixel zu ändern. mit <b>arquivo_economizar_imagens = sim</b> in config.txt werden große fotos zu webp, viel kleiner, mit kaum sichtbarem unterschied.
av-sem-scripts = <b>kopien öffnen ohne skripte</b> und laden nichts aus dem internet (keine tracker): sie sind ein „durchklickbares foto“ der seite.
av-robots = <b>der server beachtet robots.txt</b> (wenn eine website nicht kopiert werden will) und lädt langsam, um niemanden zu überlasten.
av-resp = <b>verantwortung:</b> die kopie bleibt nur auf diesem computer und niemand kann sie von außen löschen, aber die gesetze gelten weiter für den, der sie aufbewahrt (urheberrecht, personenbezogene daten). für den privaten gebrauch ist das meist zulässig; die website eines anderen weiterzugeben kann eine weiterverbreitung sein.
sobre-1 = Das ist <b>Local Server</b>. Ähnlich wie Cloudflare: er speichert Websites und liefert sie an den Browser. Der Unterschied: er wohnt <b>auf diesem Computer</b> und funktioniert <b>ohne Internet</b>.
sobre-cf = wohnt im internet. jeder auf der welt kann es öffnen, aber nur mit internet.
sobre-ls = wohnt hier. öffnet sich auf diesem computer und, wenn du es einschaltest, auf geräten im gleichen wlan. funktioniert ohne internet, und du hast die kontrolle.
sobre-2 = Der Server ist das <b>Haus</b>; jeder Ordner in <b>sites</b> ist ein <b>Bewohner</b>. Das <b>Website-Archiv</b> speichert Kopien von Websites, mit einer neuen Version bei jeder Änderung, wie ein persönliches Museum. Der ganze Ordner lässt sich auf einen USB-Stick oder einen anderen Computer kopieren und funktioniert genauso.
